# AI Companion Platform - Local Setup Guide

Welcome! This guide will walk you through setting up and running the project on your local machine.

## Prerequisites
Before you begin, ensure you have the following installed on your device:
1. **Python 3.10+** (for the backend)
2. **Node.js 18+** (for the frontend)
3. **PostgreSQL** (running locally on port 5432)

---

## Step 1: Set Up the Environment Variables
You should have received two environment files directly from the developer. Do not commit these files to GitHub.
1. Place the main `.env` file in the **root directory** of the project (`ai-companion-platform/.env`).
2. Place the `.env.local` file inside the **frontend directory** (`ai-companion-platform/frontend/.env.local`).

---

## Step 2: Database Configuration
1. Open your PostgreSQL manager (like pgAdmin or terminal).
2. Create a new, empty database named: `ai_companion`
3. Open the root `.env` file and find the `DATABASE_URL` variable. Ensure the username and password match your local PostgreSQL setup:
   `DATABASE_URL=postgresql+psycopg://<your_postgres_username>:<your_postgres_password>@localhost:5432/ai_companion`

---

## Step 3: Backend Setup
Open a terminal in the root directory (`ai-companion-platform/`) and run the following commands:

1. **Create and activate a virtual environment:**
   Windows: `python -m venv .venv` then `.venv\Scripts\activate`
   Mac/Linux: `python3 -m venv .venv` then `source .venv/bin/activate`

2. **Install Python dependencies:**
   `pip install -r requirements.txt`

3. **Run database migrations (This creates all the necessary tables in your database):**
   `alembic upgrade head`

4. **Start the backend server:**
   `uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload`
   
*(Leave this terminal running. The backend API is now alive at http://127.0.0.1:8000)*

---

## Step 4: Frontend Setup
Open a **new** terminal window and navigate to the frontend directory:
`cd frontend`

1. **Install Node dependencies:**
   `npm install`

2. **Start the frontend development server:**
   `npm run dev`

*(Leave this terminal running. The frontend is now alive at http://localhost:3000)*

---

## Step 5: Testing
Open your browser and navigate to **http://localhost:3000**. 
You can now create an account, complete onboarding, and start chatting with the AI Companion!
